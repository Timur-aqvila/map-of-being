# Как внести вклад в Карту Бытия

## 1. Предложить гипотезу
Создайте JSON-файл по схеме `schema/hypothesis.schema.json` и:
- отправьте его через нашего Telegram-бота (ссылку см. в README, скоро появится)
- или создайте Issue в этом репозитории с тегом `new-hypothesis`

## 2. Проверить связь
Возьмите любой протокол из папки `protocols/` и выполните описанные шаги.
Отрицательный результат так же ценен, как и положительный.
Опубликуйте результат как Issue с тегом `test-result`.

## 3. Написать паучка
Паучок — это программа, которая автоматически проверяет гипотезы.
Добавьте своего паучка в папку `agents/` и создайте Pull Request.

## 4. Предложить улучшение
Создайте Pull Request или Issue с тегом `enhancement`.

Все участие добровольное и открытое.
