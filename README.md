# 🗺️ Карта Бытия (Map of Being)

**Не догма. Приглашение к проверке.**

Открытая платформа для сборки и безжалостной проверки научных гипотез.
Каждая связь имеет статус и должна доказывать своё право на существование.

## Статусы связей
- `speculative` — спекулятивная идея
- `testable` — готова к проверке
- `established` — многократно подтверждена
- `falsified` — опровергнута (оторвана от карты)

## Первый закон Карты Бытия
**Истина рождается «между».**  
Самые сильные открытия возникают не внутри одной дисциплины, а на стыке двух, казалось бы, не связанных идей. Эта платформа создана, чтобы такие связи находить, проверять и — если нужно — разрывать.

## Что внутри
- JSON-схема для упаковки гипотез
- Протоколы с фальсифицируемыми предсказаниями
- Байесовский фильтр для оценки связей
- Telegram-бот для приёма новых гипотез
- Независимый аудит теорий о происхождении масс частиц
